# Innovation Project: MARL for Vehicular Edge Computing

## Quick start

Prerequisites:

- Python 3.8+
- SUMO(1.8.0) installed and available on your PATH (for TraCI)

Install dependencies:

- `pip install -r requirements.txt`

Run (in two terminals):

1. Start the PT server:
   - `python scripts/pt_server.py`
2. Start the PT runner:
   - `python scripts/run_pt.py`
